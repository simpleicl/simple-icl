# SimpleICL

This repository is the official code release for the paper **In-context Robot Learning Made Simple: A Democratized Recipe for Manipulation Tasks**.

SimpleICL is a minimalist, reproducible framework for robotic in-context learning (ICL): after watching a single human demonstration video, a robot can directly execute the corresponding manipulation task. The repository covers the complete pipeline — **data collection, model training, and deployment**.

- Project page: [simpleicl_web](https://simpleicl.github.io/simpleicl)
- Paper: [Arxiv](https://github.com/simpleicl/simple-icl)
